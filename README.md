# 페어 서사

두 사람의 장면을 **기 · 승 · 전 · 결** 같은 막에 끼워 넣어, 페어의 이야기를 한 줄기로 정리하는
한 장짜리 페이지입니다. 설치도 서버도 필요 없습니다. `index.html` 파일 하나가 전부입니다.

오리지널 옆에 **AU**를 몇 개든 붙일 수 있고, 같은 내용을 **상세버전**과 **단순버전** 두 가지 모양으로 봅니다.

## 두 가지 보기

### 상세버전 — 짜는 화면

막마다 화면이 좌우로 갈립니다. **왼쪽 레인은 A, 오른쪽 레인은 B**, 가운데로 등뼈가 흐르고
각 블럭이 짧은 막대로 등뼈에 물립니다. 두 사람이 같이 있는 장면은 **함께 블럭**이 되어
가운데를 가로지릅니다. 한 장면이 한 줄씩 내려가므로 시간 순서가 흐트러지지 않습니다.

블럭에는 제목 · 장면 이미지 · 본문 · 태그 · **감정 강도**가 들어갑니다.
왼쪽 손잡이 `⠿` 를 끌면 **순서 · 막 · 레인이 한 번에** 바뀌고(왼쪽에 놓으면 A, 오른쪽이면 B,
함께 블럭은 유지), 오른쪽 단추로 `↑ ↓` 이동 · `🖼` 이미지 · `⧉` 복제 · `✕` 삭제를 합니다.

`한눈에 보기` 를 누르면 본문과 이미지가 접히고 제목만 한 줄로 남아 전체 흐름을 훑을 수 있습니다.

### 단순버전 — 보여 주는 화면

**인물 카드 두 장**이 맨 위에 서고, 그 아래에 페어 이미지와 서사 이름 · 설정이 붙습니다.
그다음은 **사진 아래로 각자의 서사가 한 줄로** 이어지는 타임라인입니다.
왼쪽 열은 A, 오른쪽 열은 B, 함께 장면은 두 열을 가로지르고, 막은 가로 구분선으로만 남습니다.

제목과 본문은 여기서도 바로 고쳐집니다. 블럭 추가나 순서 바꾸기 같은 구조 작업은 상세버전에서 합니다.

## 인물 카드

두 화면이 같은 카드를 씁니다. 한쪽에서 고치면 다른 쪽에도 그대로 반영됩니다.

| 자리 | 내용 |
| --- | --- |
| 사진 | 둥근 정사각형. 끌어서 옮기고, 휠이나 슬라이더로 확대하고, 두 번 누르면 원위치. |
| 이름 · 나이 | 이름을 바꾸면 레인 버튼과 페어 탭이 함께 따라갑니다. |
| 색 | 인물마다 원하는 색을 직접 고릅니다. 레인 · 블럭 테두리 · 감정 곡선 · 타임라인 점이 그 색을 씁니다. |
| 한 줄 소개 | 인물을 한 문장으로. |
| 태그 | `#태그` 칩으로 보이고 `✎` 를 누르면 한 줄로 고칩니다. |
| 항목표 | `좋아하는 것 · 싫어하는 것 · 특징` 으로 시작하지만 **항목 이름도 개수도 자유**입니다. `＋ 항목 추가` 로 늘리고 `✕` 로 지웁니다. |

## 막과 블럭

막은 고정이 아니라 **서사마다 가지는 목록**입니다. 기본은 起 承 轉 結 네 개.

- 막 머리에서 **표시 글자 · 이름 · 설명 · 색**을 바로 고칩니다.
- `↑ ↓` 로 막 순서를 옮기고(안의 블럭이 따라갑니다), `＋` 로 바로 아래에 새 막을,
  `✕` 로 막을 지웁니다. 막은 하나 이상 남습니다.
- 막을 지울 때처럼 되돌릴 수 없는 일은 **페이지 안의 확인창**으로 묻습니다.
  브라우저가 기본 대화상자를 막아 둔 상태에서도 동작합니다.
- `Ctrl + Enter` 로 지금 블럭 아래에 같은 사람의 블럭을 잇고, 제목에서 `Enter` 를 누르면 본문으로 내려갑니다.

## 오리지널과 AU

페어마다 서사 탭이 있습니다. `본편 오리지널` 옆에 `＋ AU 추가` 로 AU를 몇 개든 붙이고,
AU마다 **이름 · 설정 · 페어 이미지 · 막 구성 · 블럭**을 따로 가집니다. 인물 정보와 사진은 페어 단위로 공유됩니다.
오리지널은 지워지지 않고, AU만 이름을 바꾸거나 지울 수 있습니다.

`＋ 페어` 로 다른 커플을 얼마든지 따로 관리합니다.

## 감정 곡선

블럭에 매긴 감정 값이 **두 사람의 곡선**으로 그려집니다. 함께 장면은 두 곡선 모두에 찍히고,
막이 바뀌는 자리에는 눈금이 섭니다. 두 사람의 감정이 언제 붙고 언제 갈리는지가 한눈에 보입니다.

## 저장과 내보내기

| 기능 | 설명 |
| --- | --- |
| 자동 저장 | 고칠 때마다 그 브라우저의 localStorage 에 담깁니다. |
| HTML 저장 | 지금 화면을 **파일 하나**로 내려받습니다. 사진까지 파일 안에 담기고, 편집용 단추는 빠진 읽기 전용입니다. 보기 방식과 테마도 그대로. |
| PNG 저장 | 지금 화면을 이미지 한 장으로. 상세버전이면 프로필 · 감정 곡선 · 두 레인의 블럭이, 단순버전이면 인물 카드 · 서사 소개 · 두 열의 타임라인이 담깁니다(2배 해상도, 아주 길면 1배). |
| 인쇄 | `Ctrl + P` 로 바로 인쇄하거나 PDF로 저장합니다. 도구와 편집 단추는 인쇄에서 빠집니다. |

## 테마

`백코 · 블루밍 · 블루레몬`, 그리고 색 두 개로 만드는 **그라데이션**.
그라데이션은 고른 두 색에서 배경뿐 아니라 글자색 · 선색 · 강조색까지 뽑아냅니다.
어두운 쪽 색의 색상을 살려 강조색을 만들기 때문에 파스텔을 골라도 흐려지지 않고,
카드는 흰 바탕을 유지해 어떤 두 색을 골라도 글씨가 묻히지 않습니다.

## 쓰는 법

`index.html` 을 브라우저로 열면 끝입니다.

- 적은 내용과 넣은 사진은 **그 브라우저의 localStorage 에만** 저장됩니다.
  서버로 올라가지 않고, 다른 기기·다른 브라우저와 공유되지 않습니다.
  브라우저 데이터를 지우면 함께 지워지니, 남겨 둘 것은 `HTML 저장` 이나 `PNG 저장` 으로 빼 두세요.
- 사진은 넣을 때 크기를 줄여 담습니다(페어 이미지 900px, 장면 720px, 인물 480px).
  저장 공간이 넉넉하지 않으니 아주 큰 사진을 여러 장 넣으면 저장에 실패할 수 있습니다.
  그때는 상태줄에 알려 줍니다.
- 투명한 배경의 그림(PNG)은 **흰 바탕 위에 얹어** 담습니다. 검게 깔리지 않습니다.
- 글꼴은 웹폰트(IBM Plex Sans KR · Bricolage Grotesque)를 씁니다. 인터넷이 없으면 시스템 글꼴로 보입니다.
